# ЗАТОЧКА

1. Заточка держится 8 часов. Каждую заточку записываю в журнал `ЗАТОЧКА.csv` (корень Клод мад): дата и время, персонаж, оружие, когда кончится. Делает `mudbot\tools\zatochka.py` (`статус` / `запись <персонаж> <оружие>`).

2. Перед заточкой — `zatochka.py статус`: что и когда точили. Не прошло 8 часов — не точить.

3. Оружие Кимпи точит Айкира (варвар того же аккаунта, стоит в Эрдере). Порядок:
   Кимпи `путь рента` -> `айк` -> `путь склад` -> `кз :следак4 $wpn1`, `кз :следак4 $wpn2` (оружие на текущий уровень Кимпи) -> `путь точи` (Каморка точильщика) -> `спис` -> `заточить маст $wpn1`, `заточить маст $wpn2` -> запись в журнал -> `путь склад` -> `кс :следак4 $wpn1`, `кс :следак4 $wpn2` -> `путь рента` -> `рх` -> Кимпи одевается (`путь склад`, `проверка`).

4. Пока нет эксплора Эрдера — ходить командой `путь`. Потом оформить заточку в спидволк с проверкой денег.

5. Ответ точильщика: «Демон-точильщик принялся затачивать <вещь> и вскоре вернул вам результат своих трудов.»
