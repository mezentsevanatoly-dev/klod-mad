# РАСХОДНИКИ

1. У каждого персонажа свои расходники и свои пороги.

2. Порог = сумма применений всех экземпляров одного вида; меньше порога — сообщение «МАЛО …». Считает скрипт проверки (`СКРИПТЫ\Проверка.md`).

3. Айлина (+колб2): охр 10, восс 10, мыши 10, насыщ 15, прозр 10, панац 10, камней 10, микстура освобождения 3.

4. Наборы колб по уровню: колб0 — 1–5 лвл, колб1 — 5–20, колб2 — 25+. Перед сменой набора по уровню: `сдай`, забрать новый набор, занести в текущий счётчик.

5. Счётчик зарядов: всегда знать текущее количество зарядов каждого расходника, обновлять раз в 20 минут.

6. По каждому расходнику — своя справка в папке `РАСХОДНИКИ\` (что делает, сколько зарядов, где купить, цена, сколько носить).

7. Обновление колб на складе: `сдай; +колб2` раз в 60 минут — для всех лидеров группы (соло — тоже лидер). Кимпи с 1 по 21 лвл — раз в 30 минут, с проверкой уровня (набор по п. 4).

8. Закупка — `РАСХОДНИКИ\ЗАКУПКА.md` (когда, сколько, где). Купленное — в `:Колбы` КСК. Остаток в `:Колбы` — `РАСХОДНИКИ\КОЛБЫ.md`, обновляет `проверка` любого персонажа (`кск :колбы`, количество по видам, дата и время).
