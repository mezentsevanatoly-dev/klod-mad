# ПОИСК

1. «Найди» = по всем файлам из `БИБЛИЯ.md` (включая архив), начиная с оглавления. Если нужно в конкретном файле — пользователь скажет «измени» / «пропиши».

2. Найденное кладу в файл `НАЙДЕНО\<что искали>.md` и по завершении открываю его. Дальше пользователь правит файл или говорит, что делать. Без его слова по найденному ничего не меняю.

3. Перед тем как что-то писать (код, план, вопрос пользователю) — сначала поиск по всем файлам (16.11: «перед тем, как вообще что бы то ни было писать проверяй поиском по всем файлам. я уверен, ты будешь меньше спрашивать»). Пример: план «хп ниже порога — бежать» — а в `РЕЖИМЫ.md` уже `реж трус 30`, и охранный свиток зачитывается сам.
