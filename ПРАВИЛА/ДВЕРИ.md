# ДВЕРИ

1. Двери открывает модуль `Двери.js` (`СКРИПТЫ\Двери.md`) — только по сообщению игры. В новые маршруты `.botp` команды дверей не вшивать.

2. В командах дверей направление всегда полным словом (иначе игра цепляет вещи из инвентаря).

3. Запертые двери без ключа пишутся в `двери_<персонаж>.txt` (папка JMC персонажа). Перед эксплором зоны смотреть этот файл.
