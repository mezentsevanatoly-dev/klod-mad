# АЛИАСЫ И ТРИГГЕРЫ

1. Алиас или триггер по просьбе набираю командой в открытой JMC нужного персонажа (`#alias`, `#action`, `#unalias`, `#unaction`). Работает сразу; при обычном закрытии JMC сама сохраняет профиль (в логе `>> ;#write {…<Имя>.set}`, потом `>> #killall`). Но `#reload` и необычное закрытие (15.11 15:54 — только `#killall` без `;#write`) не сохраняют, поэтому после каждого набора алиаса/триггера сразу `;#write {<полный путь>\<Имя>.set}` (с `;` впереди, иначе JMC пропускает). 15.11 так пропали алиасы ЧЕК у Айлины.
   Не делать модуль, который ловит `#killall`: при запуске JMC шлёт `#killall;#read {…}`, и такой модуль затирает `.set` пустым (15.11 17:06, `Сохранение.js` — удалён, файл восстановлен из копии). Файл `.set` напрямую не правлю, при старте JMC ничего не догружаю. Исключение: JMC персонажа не запущена и пользователь сказал делать — пишу прямо в `.set` (с копией `.bak_…` рядом).

2. Если алиас берётся из файла (`Алиасы\`) — беру строку как есть. Если в конфиге уже есть алиас с таким именем, но другой — показываю оба варианта и жду подтверждения замены.
