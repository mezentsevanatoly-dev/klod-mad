# КОНФИГИ ПЕРСОНАЖЕЙ

1. У каждого персонажа свой профиль JMC: `<Имя>.set`, `settings\<Имя>.opt`, `settings\<Имя>.js`. Айлина: `JMC БОТ АЙЛИНА\Айлина.set`. Кимпи (инкарнация): `JMC БОТ ИНКА\Кимпи.set` (сделан 15.11 из `дкаре.set`; `дкаре` не трогаем).

2. Общие команды (+сет, -сет и др.) называются одинаково во всех профилях, а внутри отличаются (отдел, количество вещей и т.п.).

3. Вход другим персонажем того же аккаунта — алиасы `постой; 3; <имя>; 1` (`айк` — Айкира, `рх` — Кимпи, `айл`, `бп`, `чвы`, `жда`, `шмы`). Работают только на ренте: в городе сначала `путь рента` (к хозяину гостиницы), потом алиас.

4. Пока на аккаунте играет Тадия, Кимпи (и другие персонажи аккаунта) зайти не может — ждать.
