# Скрипт Двери (Айлина, пригодится и боту)

Файл: JMC БОТ АЙЛИНА\scripts\Двери.js
Подключён в settings\Айлина.js строкой include("scripts/Двери.js")

Работает сам, только по сообщениям игры (справка ДВЕРИ):
- «Попробуйте сначала открыть <дверь>.» -> направление берётся из промпта (закрытый выход в скобках: Вых:(В)ЮЗ),
  при нескольких закрытых — направление последнего шага -> откр <слово> <направление полностью>
- «<Дверь> заперт(а).» -> отпер <слово> <направление>; «Вы отперли» -> откр
- «Вы открыли …» -> шаг в ту же сторону
- «У вас нет нужного ключа.» -> стоп, сообщение ЗАПЕРТО, НЕТ КЛЮЧА и запись в JMC БОТ АЙЛИНА\двери_Айлина.txt (клетка;направление;дверь;причина)
- не больше 2 попыток на дверь в одной клетке

- 15.11: при нескольких закрытых выходах направление берётся из текущего шага бота — `zons[seekstep-1]` (`Dveri.botDir()`, последние фигурные скобки `#if … {вниз}`). Бот шлёт шаги через `jmc.parse`, их `onInput` не видит — раньше бот в катакомбах Геоланта стоял у «железного люка»: модуль открывал не ту дверь («Похоже, здесь нет 'люк'»)

Слово двери — существительное из сообщения без окончания: железную решетку -> решетк, бронзовые врата -> врат, дверь в кабинет -> двер.
Направление всегда полным словом (иначе игра цепляет вещи из инвентаря: «Вы не можете отпереть веревочную петлю»).

Из игры: Вы открыли X. / Вы отперли X. / X заперта. / X не заперта. / X уже открыта. / У вас нет нужного ключа.
Выключить: #scr Dveri.enabled=false
