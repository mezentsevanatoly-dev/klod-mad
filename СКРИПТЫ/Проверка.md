# Скрипт Проверка (Айлина)

Файл: JMC БОТ АЙЛИНА\scripts\Проверка.js
Подключён в settings\Айлина.js строкой include("scripts/Проверка.js")

Алиасы:
- проверка: +сет; +колб2; ждать 2; экип -> запомнить экип в экип_Айлина.txt;
  осм каждого расходника из +колб2 (осм охр, осм 2охр ...), сумма применений,
  если меньше порога -> МАЛО ...
  + считает вещи, забранные +сет из отдела Барб3: меньше 16 -> +СЕТ ЗАБРАЛ N ИЗ 16
  + сч -> аффекты: нет «плавная левитация» -> НЕТ ПОЛЁТА
- -сет: экип и сверка с экип_Айлина.txt. Совпало -> сня все;кс :барб3 все16.
  Не совпало -> НЕТ: / ЛИШНЕЕ:, ждёт окей.
- окей: выполнить -сет после несовпадения.

Пороги: восс 10, охр 10, мыши 10, насыщ 15, прозр 10, панац 10, камней 10

## Кимпи (с 15.11)

Файл: JMC БОТ ИНКА\scripts\Проверка.js (своя копия), подключён в settings\Кимпи.js.
Комплект выбирается по уровню: алиасы `проверка` -> `#scr Proverka.start("$MyLVL")`, `-сет` -> `#scr Proverka.unset("$MyLVL")`. Нет уровня -> НЕТ УРОВНЯ, набрать счет.
- до 11: +сет = кз :следак1 все;#2 кз :следак4 битв;од все | -сет = сня все;#2 кс :следак4 битв;кс :следак1 все15
- 12–19: то же со :следак2
- 20–30: +сет = кз :следак3 все;кз :следак4 перчатка.правую;кз :следак4 перчатка.левую;од все | -сет = сня все;кс :следак4 перчатка.правую;кс :следак4 перчатка.левую;кс :следак3 все15
- +сет должен забрать 15 вещей из отдела своего уровня; полёт обязателен (НЕТ ПОЛЁТА)
- +колб2 и пороги расходников пока как у Айлины
- перчатки берутся словами перчатка.правую / перчатка.левую, не «перчатк» — иначе кс заберёт и перчатки комплекта

Другой персонаж: в начале скрипта поменять charName, setCmds, unsetCmd, kitDept, kitCount, needAffects, список расходников.

Из игры:
- осм 2охр работает (без точки)
- нет предмета: Вы не видите здесь '3охр'.

## Отдел :Колбы (15.11, у всех персонажей)
В конце `проверка` делает `кск :колбы`, считает каждый вид (`название [N]` -> N штук) и перезаписывает `Клод мад\РАСХОДНИКИ\КОЛБЫ.md` (дата, время, кто проверял). Правила закупки (`buyRules` в скрипте, `РАСХОДНИКИ\ЗАКУПКА.md`): мало -> сообщение «КУПИТЬ: …». Сейчас: микстура освобождения < 5 -> купить 30 в больнице Элендора.
