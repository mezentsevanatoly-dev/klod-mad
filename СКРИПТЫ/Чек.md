# ЧЕК — группа проверок (15.11, вместо `Проверка.js`)

Файлы (у каждого персонажа в его JMC): `scripts\Чек.js` — общий код (одинаковый у всех); `scripts\Чек_<Имя>.js` — настройки персонажа (`ChekSettings`). Подключены в `settings\<Имя>.js`: сначала `Чек_<Имя>.js`, потом `Чек.js`. Новый персонаж — скопировать `Чек.js`, сделать свой `Чек_<Имя>.js`, подключить, набрать алиасы.

| Команда | Алиас | Что делает |
|---|---|---|
| чекстаф | `чс` | `экип` → сравнить с запомненным (`экип_<Имя>.txt`): «НЕТ: …», «НОВОЕ: …» → запомнить. Ничего не надето — запомненное не трогает |
| чекколбы | `чколб` | `осм <ключ>`, `осм 2<ключ>` … по каждому расходнику из настроек; сумма применений; меньше порога — «МАЛО …» |
| чекафф | `чафф` | `сч` → есть ли аффекты из настроек; нет — сообщение (НЕТ ПОЛЁТА, НЕТ ВАМПИРИЗМА) |
| чекрасход | `чрасход` | `кск :колбы` → количество по видам в `Клод мад\РАСХОДНИКИ\КОЛБЫ.md` (дата, время, персонаж); по `buyRules` — «КУПИТЬ: …» (`РАСХОДНИКИ\ЗАКУПКА.md`) |
| -сет | `-сет` | `экип`, сверка с запомненным; совпало — раздеться (`unset` из настроек, у Кимпи по `$MyLVL`); нет — НЕТ/ЛИШНЕЕ и ждёт `окей` |

`+сет`, `+колб2` — отдельные команды, в проверки не входят.

## Когда запускаются сами (слова пользователя 15.11)
- **Одевание** `+сет; +колб2`: после команды `+колб0/1/2` через 3 с — по очереди `чс`, `чколб`, `чафф`.
- **Раздевание** `сдай; -сет`: `-сет` сам делает чекстаф (сверка с запомненным; не совпало — ждёт `окей`).
- **`чрасход`**: при первой загрузке любой JMC за день — на первом промпте смотрит дату в `РАСХОДНИКИ\КОЛБЫ.md`; не сегодняшняя — запускает. `кск :колбы` работает не только на складе.

Настройки персонажа (`Чек_<Имя>.js`): `charName`, `needAffects` [аффект, сообщение], `items` [ключ осм, порог, слово для МАЛО], `buyRules` [название в :Колбы, меньше скольки, что купить], `unset(lvl)`.

Сообщения — на экран JMC и в лог `## CHEK …`.

Алиасы: `одеться` = `+сет;+колб2` (после него сами чс, чколб, чафф); `раздеться` = `сдай;-сет` (-сет сверяет экипировку).
