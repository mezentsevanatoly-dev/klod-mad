# Триггеры зон (квесты) — найдено 15.11

Источник: `JMC\Default.set` (старый профиль пользователя). Ни у Айлины (`Айлина.set`), ни у Кимпи (`Кимпи.set`) их нет — поэтому 15.11 эксплор на Затерянном острове пытался бить Старого Хасима («не пускает вас на север»).

Строки как есть: `гг !…` — команда группе; `смен меч, …` — смена оружия под квест. В конце каждой строки в файле стоит `{5} {default}`.

## Затерянный остров («кораблик»), вход из Элендора: «Перед школой магических искусств» (100124) на север
```
#action {Старый Хасим сказал: "Тебя интересуют путешествия в неизведанные земли?"} {гг !дать 500 хасим; дать 500 хасим}
#action {Старый Хасим проводил вас в одну из комнат дома.} {гг !войти; войти}
#action {Старый Хасим сидит за столом, погрузившись в собственные мысли.} {дать мешоч хасим}
#action {Вдова вождя горько оплакивает смерть своего мужа} {дать останки вдов}
#action {Внутри дольмена установлен алтарь, представляющий собой цельный черный} {установить статую}
#action {Вы стоите внутри уходящей вглубь скалы ниши с низкими потолками. Здесь царит} {развязать скелет; взя все}
#alias {пк} {гг !плыть корабль; плыть корабль}
#alias {по} {гг !плыть остров; плыть остров}
```
Маршрут из старых ботов (`Мад\Копия Мад\jmc\areas\рр2_Кораблик.botp`, `БОТ ЧВЫРЛА\areas\Слава_Кораблик.botp`): `дать 500 хасим` -> `войти` -> … -> `плыть корабль` -> (корабль, двери, сундук) -> `плыть остров` -> `г помогу`, скелеты, `дать кост вд`, `установить статую` -> … -> `дать меш хас`.
