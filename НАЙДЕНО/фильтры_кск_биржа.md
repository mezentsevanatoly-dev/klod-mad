# НАЙДЕНО: фильтрация, КСК, биржа (15.11)

## Справка (`СПРАВКА.md`)
ФИЛЬТР_ПРЕДМЕТОВ, БИРЖА, КЛАНСКЛАД, СКЛАД, ОТДЕЛЫ_КЛАНСКЛАДА, ОТДЕЛЫ_СКЛАДА, ОЦЕНКА_ПРЕДМЕТОВ, ИДЕНТИФИКАЦИЯ, ОСОБЕННЫЕ_ПРЕДМЕТЫ, ЭКИПИРОВКА, СОКРАЩЕНИЯ, ГРАДАЦИИ_АФФЕКТОВ. Сжато — `Экип\фильтры.md`.

Ещё из справки:
- КСК: `кз [:отдел [пароль]] <вещи>`, `кс [:отдел] <вещи>` (без отдела — Общий), `кпереслать <кому>|:<отдел> ...`, `переслать клан :<отдел> ...`, журнал — `журнал ксклад`. Вместимость 1000.
- Личный склад: 150 вещей, `сдать`/`забрать`/`переслать`, отделы `склад отдел ...`.
- Биржа (работает везде, деньги с банковского счёта, вещь — на склад): `биржа купить <лот>`, `выставить <вещь> <цена>` (10 монет + 1%), `цена`, `снять`, `оценить`, `автовыставить`, `фильтрация <цена|тип>` (какие сообщения биржи показывать).
- Особенности (звёзды): `особенность <вещь> <свойство>`; первое улучшение свойства — 1 пункт запаса, повторное того же — 2.
- Максимальная градация аффекта по уровню: 21–25 — 4, 26–30 — 5.

## Слова пользователя (архив «Клод старое», фразы)
- 23.10: «фильтры предметов `кск * од *доп =варвар =8 ?ПОЛЕТ !10` например».
- 23.10, 03.11, 06.11: уникальные свойства видно только через `кск х`, `б х` (или познание); не видишь цвета — только `х`.
- 01.11: «ты плохо посмотрел кск, я же тебя учил `кск * од *шея =я` (можно =профессия =уровень)». Брать со всех отделов, кроме :Друид и :Денар. Оружие — под профессию (фламберг = длинные лезвия — ошибка для Айлины).
- 01.11: «Сборная солянка» — заготовки алиасов для кск и биржи варваром на 1, 8, 12, 15, 18, 20, 23, 25, 28 лвл. Строка 5 «вот так надо»: `кск * од *доп =варвар =18 !30;кск * од *доп =варвар =18 ?ас +4;кск * од *доп =варвар =18 ?ас +2 ?ловк;кск * од *доп =варвар =18 ?ас +2 ?доп.атак;`, с 6-й — другие слоты.
- 06.11: «я учил не только кск использовать, но и биржу». Сначала собрать комплект из КСК, потом проверить биржу — может найдётся лучше. Рюкзак — это доп слот (`*доп`).
- 01.11 (как выбирать вещи): главное — АС (с учётом потенциала звёзд), потом броня, звёзды, таймер, статы/бонусы к умениям, цена. Таймер не увеличить — дорогую вещь с малым таймером не брать.

## Архив: как пользователь одевал варвара на 18 (`Клод старое\mudbot_data\dress_rules.md`)
По слоту `кск * од *<слот> =варвар =18 !30` (мало — `!50`/`!70`) -> `кск х <вещь>` -> `кз :<отдел> <вещь>` -> `од` -> `э`, лишнее обратно `кс`. Биржа: `биржа предл од *<слот> =варвар =18 !30` -> `б х <лот>` -> `б к <лот>`. Звёзды тратить: `особ <вещь> <свойство>`. Уже улучшенная копия (`*`) имеет оценку выше, чем `***`.
