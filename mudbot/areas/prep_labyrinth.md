Источники: `БОТ ЧВЫРЛА\areas\рр5_Лабиринт.botp` (180 строк, cp1251) + `рр5_Лабиринт_mob.csv` (91 моб, все ур. 27, 3 мирных: агитатор, старец, искатель, привратник), `data/world/Лабиринт.json` (35 клеток, id 1..35 = vnum 556001..556035).

## Маршрут Чвырла
1. Старт в обычном мире: идти по клеткам зон 125 -> 112 -> 105 -> 104 -> 107 -> 115 -> 118 -> 199 (шаги 4-136, ~130 клеток; в начале `look краткий;БотОдеться`; ловушка: «Пущенный катапультой снаряд попал в вас!» -> `вст; ждать 40; вст`).
2. 125077 `вниз`, затем 199001..199009: на 199009 создание области: `#loopback Создание_области:восток; обл удал в; обл с в; од все; ждать 25`, потом `восток`. (Для нас: `обл с в`, а старую `обл удал в` писать ТОЛЬКО если активна; статусы — `обл`.)
3. Внутри области 556 (35 клеток, мобы ур.27): `реж вещи да; реж труп да` в 556015 (север), обход всех комнат по DFS-подобной цепочке (шаги 139-179).
4. 556008 (Сокровищница?): `отпер лар; отпер сун; откр лар; откр сун; взя все лар; взя все сун`, затем `юг`; конец: `запад` из 556015, `реколим`.
5. Циклы seekstep: 4, 26, 45, 69, 94, 120, 137, 154, 169 — это просто «возврат к шагу», у нас нет `seekstep`.

## Для Тадии
- Мобы ур.27, hp ~1340 (из csv) — землетрясение справится; мирные не бить.
- Из мира 199 вход в область — в нашем Ривенделле/Галене искать выход к зоне 125 (карты в `data/world/`?). Путь до 199009: считать по картам (goto).
- Открыть: нужен ли квест (вики не читала), что за награды (славы нет у Чвырлы). Сундуки: лар/сун в 556008.

## Поправки пользователя
- Выход из зоны пешком (рекол не нужен). Катапульта «Пущенный снаряд…» — из Амон Сула, не Лабиринт.
- Дорога: аватара -> город Геолант; Лабиринт на ВОСТОКЕ от центральной площади Геоланта по пыльному тракту. ДТ и секретов нет, надо запомнить путь и открыть 1-2 сундука.
