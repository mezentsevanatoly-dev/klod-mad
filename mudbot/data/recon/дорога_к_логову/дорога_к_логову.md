# Дорога Геолант → Логовище орды (эксплор Айлиной 14.11.2026)

Слова пользователя: Аватара → Перекресток миров → `путь видрир` → в Видрире `путь дирижабль` → `ехать 1` (Видрир - Хутор Аргниста, 500) → хутор Аргниста → к Логову. В дирижаблях, как в конюшнях, команда `ехать НОМЕР` (`куп` не работает: «Вы не видите здесь продавца»).

## Шаги (проверено)
1. Геолант, склад (р2) → `путь аватар` (Портал в пустоту) → `войти` → Веранда, `куп 1` (2000, перенос на Перекресток миров; группа `куп 2`).
2. Перекресток миров: `путь видрир` (идёт автоматически по тропам пустоты) → «Портал в Видрир» → `войти`.
3. Видрир: `путь дирижабль` → «Площадка воздушных шаров», `список`: 1 Видрир - Хутор Аргниста (500), 2 Видрир - Гален (1000). `ехать 1`.
4. Прилёт: «Насест клювокрылов» (хутор Аргниста), выход `вниз` → «Стойло защитников».

В Видрире на пути к дирижаблю у «Входа в Храм» стоит чумная группа (Облако ядовитых испарений, Жуткое порождение (невидимо), Больной старик, Воин, пораженный болезнью, Темный всадник, Охранник): они не напали, проходить, не бить (ассист).
