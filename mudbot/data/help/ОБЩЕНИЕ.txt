СОЮЗ_ГОВОРИТЬ ГРУППА_ГОВОРИТЬ

   Одна из самых важных составляющих игры - это общение. Для этого в нашем маде
существует много различных каналов и команд. Каналы общения бывают следующими:

  Общие      - Общие или, другими словами, публичные каналы. Сообщения в них
               видны всем игрокам, независимо от того, спит персонаж или нет, а
               также видит ли он того, кто произнес фразу. Общие каналы не
               предназначены для РП-общения, они скорее для общения между
               игроками-людьми. Команды: 'болтать', 'орать'.
  Новички    - Канал общения для новичков, где они могут получить информацию о
               мире у более опытных игроков. Команды: 'нговорить'.
  Клановые   - Клановые каналы есть у персонажей, которые состоят в кланах, и
               служат для общения внутри клана. Сообщения видны только игрокам,
               которые находятся с вами в одном клане. Команды: 'кговорить'.
  Зона       - Сообщения видны только игрокам, которые находятся с вами в одной
               зоне. Команды: 'кричать' ('крикнуть').
  Комната    - Сообщения видны только игрокам, которые находятся с вами в одной
               комнате. Команды: 'говорить'.
  Группа     - Сообщения видны только игрокам, которые находятся с вами в одной
               группе. Команды: 'гговорить'.
  Личные     - Сообщения видит только тот игрок, которому оно адресовано.
               Команды: 'сказать', 'ответить', 'шепнуть'.

   Команды 'болтать' и 'орать' отличаются только цветом выводимого сообщения, но
старайтесь не привлекать понапрасну внимание окружающих. Команда 'ответить'
аналогична команде 'сказать', только говорит тому, кто последним сказал вам
что-либо.
   Если вы, например, теряли связь, или просто хотите еще раз прочитать
последние обращения других игроков к вам, используйте команду 'вспомнить',
которая покажет вам последние 20 сообщений.

Синтаксис:
  болтать <текст>
  орать <текст>
  нговорить <текст>
  кговорить <текст>
  кричать <текст>
  говорить <текст>
  гговорить <текст>
  сказать <имя> <текст>
  ответить <текст>
  шепнуть <имя> <текст>
  вспомнить

Примеры:
  болтать Всем привет!
  нговорить Какая раса лучше для воина?
  кговорить Когда идем зонить?
  кричать Есть кто в зоне?
  говорить Дайте воды.
  гговорить Где сбор?
  сказать Асхилл Привет, как дела?
  ответить Здравствуй, нормально :)
