ЕЖЕНЕДЕЛЬНЫЕ_ЗАДАНИЯ ЗАДАНИЯ ЗАДАНИЕ

   Еженедельные задания - это небольшие квесты, доступные персонажу для
выполнения один раз за неделю. Как правило, еженедельное задание связано с
некоторой зоной и выполняется полностью внутри нее. Для завершения задания нужно
выполнить один или несколько этапов, таких как: победить какого-либо моба,
отпереть какой-либо сундук или применить тот или иной триггер. В награду за
завершение задания игроки получают некоторое количество славы, подробнее см.
раздел СЛАВА, также возможны награды в виде опыта, денег и пр. Награду за
выполнение каждого задания персонаж может получить только один раз за неделю,
при повторном выполнении того же самого задания в ту же неделю награда уже не
выдается.
   Для выполнения еженедельных заданий существует несколько важных условий.
Во-первых, еженедельные задания нельзя выполнять в базовых экземплярах зон, для
их выполнения обязательно нужно создавать новую область. Во-вторых, награда за
еженедельные задания не выдается в ночное время, когда разрешен автономный
ботинг. В-третьих, награду за еженедельные задания получают только персонажи с
уникальных аккаунтов. Неопределенные аккаунты и аккаунты-мульты награды не
получают.
   Награда за выполненное в некоторой зоне еженедельное задание выдается каждому
уникальному персонажу, лично присутствовавшему при выполнении каждого его этапа.
Причем величина награды, получаемая каждым уникальным персонажем, делится на
общее количество посетителей данного экземпляра зоны (в т.ч. мультов и
неопределенных). Например, если посетителями области является один уникальный
персонаж, два мульта и два неопределенных, то уникальный персонаж получит за
выполнение этого задания только 1/5 награды, прочие же персонажи награды не
получат. Задание запоминает на одну неделю, с каким результатом оно было
пройдено, поэтому в течение той же недели свой предыдущий результат можно
улучшить, выполнив то же самое задание с меньшим числом персонажей или вообще в
одиночку, а также, возможно, с одним из доступных бонусов - герольда или группы
без ботов. В этом случае уникальный персонаж в награду получит разницу между
новым и старым достигнутым результатом.
   На получаемую в награду за выполнение еженедельных заданий славу могут
действовать различные бонусы. Например, использование персонального герольда,
нанятого в Зале Героев, удваивает получаемое персонажем количество славы. Также
увеличенное количество славы получают персонажи в режиме группы без ботов. Оба
этих бонуса могут действовать совместно.
   Посмотреть список доступных заданий можно с помощью команды 'задания', для
которой можно задать несколько аргументов.

Синтаксис:
  задания              - посмотреть список заданий, доступных в текущей
                         зоне, как выполненных, так и выполняемых
  задания все          - вывести список всех доступных в зонах заданий
  задания выполненные  - вывести список выполненных вашим персонажем
                         за текущую неделю заданий
  задания прогресс     - вывести информацию об этапах еще не выполненных
                         вашим персонажем заданий
