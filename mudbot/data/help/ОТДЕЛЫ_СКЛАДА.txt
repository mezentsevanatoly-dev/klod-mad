ОТДЕЛЫ_СКЛАДА СКЛАД_ОТДЕЛЫ СКЛАД_РЕНТА

   Отделы личного склада - это его составные части, для каждого отдела можно
задавать свое название и устанавливать свой уровень ренты. По умолчанию на вашем
складе существует единственный раздел - Общий. Доступ к нему не требует никаких
особых команд. Все операции, для которых не указан отдел, будут производиться
именно с отделом Общий. При возникновении необходимости можно создать другие
отделы. Таким образом можно сортировать предметы внутри вашего личного склада,
задавать разные режимы их хранения, а также быстро и удобно находить нужные вам
вещи. Все операции с отделами проводятся с помощью группы команд 'склад отдел':

 1. При создании нового отдела требуется указать его название. Название должно
быть не длиннее 10-ти букв и состоять только из разрешенных символов: буквенные
символы, цифровые, '-' и '_'. Также на складе не может быть таких отделов, что
название одного из них является началом названия другого.
   склад отдел добавить <название>

 Примеры:
  склад отдел добавить сет - создать на личном складе отдел Сет

 2. При удалении отдела все его предметы переходят в отдел Общий. Для удаления
отдела следует указать его название. Не перепутайте, команда не запрашивает
подтверждение на удаление.
   склад отдел удалить <название>

 3. Переименовать отдел можно с помощью команды
   склад отдел название <старое_название> <новое_название>

 Примеры:
  склад отдел название сет сет_соло - переименовать отдел Сет в Сет_соло

 4. Установить ренту отдела можно с помощью команды
   склад отдел рента <название> <уровень_ренты>

   Доступные значения ренты - от 0 до 8. Подробнее о разных уровнях ренты можно
прочесть в разделах справки СКЛАД и РЕНТА.

 5. Общую информацию об отделах личного склада можно просмотреть с помощью
команды
   склад отдел информация

   Будет отображен список всех отделов с их номерами и названиями, количеством
предметов внутри каждого из них и стоимостью их ренты.
