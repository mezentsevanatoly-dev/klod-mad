ГРУППА_БЕЗ_БОТОВ РЕЖИМ_БЕЗ_БОТОВ !БОТ НЕБОТ

   Некоторые игроки могут включать для своей группы особый режим, т.н. режим
группы без ботов. Пока этот режим активен, группа будет получать во время
зонинга значительные бонусы. За убийство мобов будут даваться тройная сумма
золота, двойной опыт, также будет удваиваться шанс появления рукописи, символа и
реагента. Максимально возможная величина получаемого опыта по уровню также
увеличивается в два раза. Шанс появления квестовых предметов для персональных
квестов и квестов чувствующего астрал будет увеличиваться в полтора раза. Также
при создании экземпляров зон будет удваиваться шанс появления вещей на мобах и в
контейнерах, за квесты будет выдаваться двойная награда.
   Количество славы, получаемое при выполнении еженедельных заданий, будет
увеличиваться в полтора раза. Кроме того, при расчете количества получаемой за
выполнение задания славы в режиме группы без ботов все уникальные персонажи
будут расцениваться как один. То есть при наличии в группе трех
персонажей-мультов награда составит 25% максимальной, а если таких персонажей
нет совсем, - 100%.
   Режим группы без ботов считается активным, только если для группы выполняются
некоторые специальные условия. Уникальных персонажей в такой группе не должно
быть меньше половины от численности группы. Уникальных персонажей в группе
должно быть не менее трех.
   Может быть включен также особый режим группы без ботов со всеми теми же
условиями, что перечислены выше, но при котором число уникальных персонажей в
группе равняется двум. В этом случае персонажи в группе также будет получать все
указанные бонусы, но в меньшем объеме: вместо тройной награды они будут получать
двойную, вместо двойной - полуторную, а вместо полуторной - бонус +25%.
   Режим группы без ботов может быть включен на три часа каждый день. По
истечении назначенного времени режим автоматически отключается. Просмотреть
данные о режиме можно с помощью команды "режим !бот", команда покажет, включен
режим или нет, оставшееся время действия и позволяют ли выполненные условия
пользоваться бонусом группы без ботов. Включить режим можно командой "режим !бот
да", выключить - "режим !бот нет". Будьте внимательны, минимальный срок действия
режима - 15 минут, поэтому в момент выключения режима вы можете потерять время
из уже включенного пятнадцатиминутного периода.
   Все уникальные персонажи в группе с включенным режимом группы без ботов будут
периодически проходить проверку присутствия. Подробнее см. раздел справки
ПРОВЕРКА_ПРИСУТСТВИЯ. В случае, если персонаж не сможет пройти эту проверку,
режим группы без ботов для его группы будет автоматически отключен, а оставшееся
время действия бонуса уменьшено на 1 час.
   Если персонажу нужно отвлечься от игры во время включенного режима группы без
ботов, он может установить режим AFK. Персонажи с этим режимом не проходят
проверку присутствия. Однако эти персонажи также не учитываются при подсчете
уникальных персонажей группы, которых для выполнения условий должно быть не
менее трех. Также учтите, что если персонажи из группы без ботов начнут бой, то
режим AFK у всех включивших его согруппников будет сброшен. Также будьте
осторожны, многие триггеры пользовательских клиентов могут сбивать установленный
режим AFK.
   Существует также особый персональный режим !бот, который может включать для
себя отдельный игрок. Подробнее о нем можно узнать в разделе справки
ПЕРСОНАЛЬНЫЙ_РЕЖИМ_!БОТ.

Синтаксис:
  режим !бот     - просмотреть информацию о текущем значении режима
  режим !бот да  - включить режим группы без ботов
  режим !бот нет - выключить режим группы без ботов
