ПЕРСОНАЛЬНЫЕ_КВЕСТЫ ПЕРСОНАЛЬНЫЙ_КВЕСТ ПОТЕРЯЛ ОТМЕНА ОТМЕНИТЬ ОТКАЗАТЬСЯ

   Персональные квесты - это квесты, которые выдаются отдельным персонажам,
причем каждый такой квест персонаж сможет выполнить только один раз. Один и тот
же персональный квест одновременно могут выполнять неограниченное количество
персонажей. Такие квесты отличаются от обычных, как правило, более высокой и
разнообразной наградой.
   Получить персональный квест можно, аналогично обычным квестам, у специальных
мобов. Список таких мобов приведен ниже. Иногда для получения персонального
квеста персонажу нужно соответствовать некоторым требованиям, это может быть
требование уровня, профессии, расы, владения навыком. Узнать, какие квесты можно
получить и каким требованиям для этого нужно соответствовать, можно, осматривая
мобов, выдающих персональные квесты. Также для получения одного квеста вам
сначала может потребоваться выполнить другой квест. Таким образом, некоторые
персональные квесты соединены в цепочки: как только персонаж выполняет один
персональный квест, ему тут же выдают следующий.
   Взятый персональный квест можно отменить, для этого достаточно прийти к
квестеру и произнести фразу "отмена". Квест удалится из списка заданий
персонажа, однако если у данного квеста есть время репопа, то взять его снова
игрок сможет только спустя данное время.
   Информацию о текущих персональных квестах можно получить с помощью команды
"квесты". Для каждого квеста там будет указано его название, краткое описание, а
также пункты задания, которые нужно выполнить.

Cинтаксис команды 'квесты':
  квесты              - вывести список квестов, активных для вашего
                        персонажа в текущей зоне
  квесты все          - вывести полный список квестов вашего персонажа
  квесты <номер>      - вывести квест под указанным номером
  квесты <строка>     - вывести список квестов, в описании которых есть
                        указанная строка
  квесты репоп        - вывести список из выполненных вашим персонажем
                        квестов, ожидающих репопа
  квесты персональные - вывести полный список персональных квестов вашего
                        персонажа
  квесты общие        - вывести полный список общих квестов вашего
                        персонажа (квестов, доступных при каждом
                        прохождении зоны)
  квесты слова        - вывести информацию о прохождении квеста с поиском
                        слов (см. КВЕСТ_ПОИСКА_СЛОВ)

   Узнать, относятся ли некоторые мобы, предметы или комнаты к тому или иному
персональному квесту, можно, осматривая их.
   Для выполнения некоторых квестов персонажу будут выдаваться специальные
предметы. Некоторые квесты невозможно пройти без наличия таких предметов. Если
же эти предметы были утеряны, то следует вернуться к мобу, выдавшему задание
(или давшему такой предмет в качестве награды), и сказать "потерял"
("потеряла"). В этом случае моб заново выдаст персонажу все необходимые для
выполнения задания предметы.
   К сведению билдеров, персональные квесты могут быть созданы напрямую в
редакторе зон без добавления какого-либо кода, а потому любой желающий может
стать автором персонального квеста и получить за это награду, подробности можно
узнать у администрации сервера.
