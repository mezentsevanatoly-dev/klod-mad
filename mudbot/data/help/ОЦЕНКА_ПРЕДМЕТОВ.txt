ОЦЕНКА_ПРЕДМЕТОВ СЕТ

   Оценка предмета представляет собой число, которое означает его примерную
ценность и полезность для персонажа. Оценка выдается предмету в одной из
нескольких категорий: ценность для воинов, ценность для варваров, для
следопытов, для воров, для паладинов, для рыцарей смерти, для магов, для
друидов, для лекарей и для некромантов. Также рассчитывается ценность предмета
для сетов, то есть ценность в случае, когда предмет не одевается на персонажа, а
хранится на складе. Оценка рассчитывается только для предметов типа 'Одежда'.
Оценка не имеет прямого отношения к стоимости предмета, так как одинаковая
ценность может иметь разную стоимость для разных слотов экипировки. Оценка
предмета выводится при его опознании заклинанием, а также на бирже и складе.
Возможен поиск по бирже и складу с указанием минимальной оценки найденных
предметов. Оценка не выводится для тех категорий, где она равняется нулю. Ниже
указан пример предмета с ненулевой оценкой для кастеров и рыцаря смерти:
 Предмет 'черные нарукавники', Тип предмета: Одежда
          Дк   Ма   Др   Ле   Не 
 Оценка:  43,  47,  47,  41,  51

Смотрите также: ИДЕНТИФИКАЦИЯ, БИРЖА, КЛАНСКЛАД
