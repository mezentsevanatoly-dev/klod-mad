ОТДЕЛЫ_КЛАНСКЛАДА КЛАНОТДЕЛЫ СЕТЫ ОТДЕЛЫ_КСК КСК_ОТДЕЛЫ КЛАН_ОТДЕЛЫ

   Отделы - это части кланового склада, объединенные одним названием, номером,
режимом доступа и многими другими параметрами. По умолчанию на клановом складе
существует единственный раздел - Общий. Доступ к нему не требует никаких особых
команд. Все операции, для которых не указан отдел, будут производиться именно с
отделом Общий. При возникновении необходимости можно создать другие отделы,
таким образом можно сортировать предметы внутри кланового склада, запрещать
массовый доступ к некоторым группам предметов, а также быстро и удобно находить
нужные вам вещи. Все операции с отделами проводятся с помощью группы команд
'клан отдел':

 1. Возможность добавления новых отделов есть только у лидера клана, при
создании он указывает название отдела, а также некоторые из его основных
параметров. Слоты для предметов нового отдела выделяются из отдела Общий.

   клан отдел добавить <название> [м<число>] [М<число>] [*закрытый]

  название - должно быть не длиннее 10-ти букв и состоять только из разрешенных
символов: буквенные символы, цифровые, '-' и '_';
  м<число> - указывает минимальный размер данного отдела. Он означает количество
предметов, для которого всегда найдется место в данном отделе, или, если иначе,
количество пустых слотов, которые не смогут занять другие отделы. По умолчанию
значение равно нулю;
  М<число> - указывает максимальный размер данного отдела. Количество предметов
в данном отделе не может превысить это значение. По умолчанию значение равно
1000;
  *закрытый - параметр, обозначающий режим доступа к отделу, наряду со списком
доступа определяет возможность использования данного отдела. Открытым отделом
могут пользоваться все, кроме тех, кто занесен в список, закрытым - наоборот -
только те, кто находится в списке. По умолчанию все отделы открытые;

 Примеры:
  клан отдел добавить ингр м10 - создать открытый отдел Ингр с минимальным
размером 10 слотов;
  клан отдел добавить асхилл м20 М20 *з - создать закрытый отдел размером 20
слотов ровно под названием Асхилл;
  клан отдел добавить воин - создать открытый отдел с размерами по умолчанию;

 Номера отделам присваиваются в порядке их создания, согласно примеру отделы
получат следующие номера: 1 - Общий ( всегда ), 2 - Ингр, 3 - Асхилл, 4 - Воин.

 2. Возможность удаления отделов есть только у лидера клана. При удалении отдела
все его предметы переходят в отдел Общий. Отдел можно указать названием, не
перепутайте, команда не запрашивает подтверждение на удаление.

   клан отдел удалить <отдел>

 3. Просматривать информацию об отделах могут все члены клана, для этого
предусмотрена команда 'клан отдел инфо'. В команде указывается название или
номер отдела, а также параметры для просмотра.

   клан отдел инфо [<отдел>] [*] [?]

 название - указывает на отдел, о котором следует вывести информацию, если
название не указано, то выводится общая информация по структуре клансклада:
отделы, их размеры, заполненность, режимы доступа, сумма ренты и прочее;
 Следующие параметры возможны, только если указан целевой отдел:
 параметр '*' - указывает на то, что к данному отделу следует также вывести его
список доступа;
 параметр '?' - указывает на то, что к данному отделу следует также вывести и
его содержимое;

 Примеры:
  клан отдел инфо - вывести общую информацию о клановом складе;
  клан отдел инфо асхилл ? - вывести информацию об отделе Асхилл и показать
вещи, которые на нем лежат;
  клан отдел инфо Общий * ? - показать полную информацию об Общем отделе;

 4. Изменять параметры отделов могут магистры и лидеры клана, основное
назначение - редактирование списка доступа, однако другие параметры тоже
доступны для изменения. Параметры Общего отдела изменять нельзя.

   клан отдел параметры <отдел> [н<новое название>] [+<имя> ...] [-<имя> ...]
[м<число>] [М<число>] [*закрытый] [*открытый] [*стереть]

  отдел - определяет отдел, параметры которого следует изменить;
  н<новое название> - изменяет текущее название отдела:
  *стереть - очищает список доступа данного отдела, эта команда, если она
указана, выполняется раньше всех других изменений;
  *открытый - изменить режим доступа данного отдела на открытый;
  *закрытый - изменить на закрытый;
  +<имя> - добавляет персонаж в список доступа отдела;
  -<имя> - удаляет персонаж из списка доступа отдела;
  м<число> - изменяет минимальный размер отдела;
  М<число> - изменяет максимальный размер отдела;

 Примеры:
  клан отдел параметры Асхилл *с *з +Асхилл +Этхилл +Огхилл м20 М20 - очистить
список доступа отдела Асхилл, сделать его закрытым, добавить в список разрешения
Асхилла с его мультами, а также изменить размеры отдела до 20 слотов ровно;
  клан отдел параметры Рукописи нНалетай *о +Асхилл - переименовать отдел
Рукописи в отдел Налетай, сделать его открытым и добавить Асхилла в список
запрета доступа;

 5. Каждому отделу можно указывать собственный уровень ренты, все предметы будут
храниться с тем качеством, которое установлено для их отдела. Оплата ренты
зависит от количества хранящихся вещей, более подробно об этом можно узнать в
топике КЛАНРЕНТА. Изменять уровень ренты могут лидеры и магистры клана.

   клан отдел рента <отдел> <число>
   Отдел можно указать по названию или по номеру, число в диапазоне от 0 до 8
соответствует аналогичным уровням ренты для обычных складов. Обратите внимание,
что команда 'клан рента' изменяет уровень ренты одновременно для всех отделов.

 6. У каждого отдела есть свой ранг, он соответствует минимальному рангу
персонажа, который будет иметь доступ к этому отделу. По умолчанию ранг равен
трем, то есть к отделу имеют доступ все, кто рангом не ниже ветерана. Особым
отделам можно устанавливать повышенный ранг: 4 - для магистров и лидеров или 5 -
только для лидеров, ранг 2 доступен всем, кроме новичков клана, а 1 - всем без
исключения.

   клан отдел ранг <отдел> <число>

 7. Для некоторых отделов можно установить пароль, чтобы к нему имел доступ лишь
тот, кому этот пароль был сообщен. Пароль может установить только основной лидер
клана (его имя выводится по команде 'клан инфо'). Пароль не может быть
установлен для отдела 'Общий', длина пароля ограничена 20 символами. Подробнее о
проверке паролей можно прочитать в разделах справки для команд 'кзабрать' и
'кпереслать'.

   клан отдел пароль <отдел>                   - просмотр пароля
   клан отдел пароль <отдел> - <старый пароль> - сброс пароля
   клан отдел пароль <отдел> <новый пароль> <старый пароль>
                                               - изменение пароля

   Если у отдела не установлен пароль, то старый пароль при установке нового
указывать не нужно. По умолчанию ни у одного отдела пароль не установлен.
