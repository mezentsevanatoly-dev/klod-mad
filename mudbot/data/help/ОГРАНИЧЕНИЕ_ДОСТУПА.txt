ОГРАНИЧЕНИЕ_ДОСТУПА BAN ИГРА_С_1ГО_АЙПИ

   В случае бана IP-адреса клуба или сети есть возможность игры с него избранным
персонажам. Для этого нужно обратиться к старшим имморталам для установки
администратора этого IP-адреса, который будет нести ответственность за своих
игроков.

Синтаксис:
  бан <ip>                 - показать общую информацию
  бан <ip> админ [имя]     - установить администратора
  бан <ip> добавить <имя>  - добавить в список <имя>
  бан <ip> убрать <имя>    - убрать из списка <имя>

Примеры:
  бан 200.200.200.200 добавить Асхилл
  бан 200.200.200.200 убрать Асхилл

Смотрите также: ПРАВИЛА, БОГИ
