ИГНОРИРОВАНИЕ IGNORE

   С помощью команды 'игнорирование' вы можете настроить список тех персонажей,
обращения которых вы не желаете видеть.

Синтаксис:
  игнорирование список          - показать весь список
  игнорирование добавить <имя>  - добавить в список <имя>
  игнорирование убрать <имя>    - убрать из списка <имя>
  игнорирование очистить        - очистить весь список
