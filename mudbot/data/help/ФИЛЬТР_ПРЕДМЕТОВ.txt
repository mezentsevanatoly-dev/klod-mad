ФИЛЬТРАЦИЯ_ВЕЩЕЙ ФИЛЬТРАЦИЯ_СКЛАДА ФИЛЬТРАЦИЯ_КСК

   Фильтрация предметов бывает часто полезна в случаях, когда вам нужно найти на
складе или на бирже вещи, удовлетворяющие каким-либо определенным критериям.
Далеко не всегда удобно пролистывать список из нескольких страниц в попытках
подобрать что-то нужное для себя, гораздо проще заранее указать необходимые
условия отбора и в конечный список попадут только вещи, которые действительно
могут вас заинтересовать.
   Фильтрацию предметов можно использовать в трех случаях: при просмотре
предметов на бирже, на клановом или на личном складе. В каждом из этих случаев
параметры фильтрации задаются с помощью особой строки, имеющей специальный
формат.
   На первом месте в строке фильтрации должно идти указание типа предметов для
поиска со следующими возможными вариантами (перечисленные слова можно указывать
с сокращениями):

  все          - все предметы
  одежда       - только одежда
  оружие       - только оружие
  подщит       - предметы типа Обычный, которые можно держать
  книга        - только книги
  свиток       - только свитки
  напиток      - только напитки
  ингредиент   - только ингредиенты
  реагент      - только реагенты
  символ       - только символы
  руна         - только руны
  инструмент   - только инструменты
  пища         - только пища
  ключ         - только ключи
  источник     - только источники
  прочее       - все прочие типы предметов
  уникальный   - уникальные предметы
  особенный    - особенные предметы
  рунный       - предметы со вставленными рунами
  мой          - мои лоты (только для поиска по бирже)
  клан         - лоты моего клана (только для поиска по бирже)

Примеры:
  биржа предложения клан
  клан склад рунный
  склад ингредиент

   Вслед за указанием типа предметов в строку фильтрации можно в любом порядке
добавлять дополнительные параметры поиска.

   Поиск по подтипу. Указывается после знака * (например *обувь). Для одежды
можно указать слот, на который ее можно надеть: допслот, голова, шея, тело,
плечи, талия, кисти, руки, ноги, обувь, запястье, палец, щит. Для ингредиента
можно указать цвет: белый, желтый, зеленый, синий, голубой, красный, фиолетовый,
серый, черный, бирюзовый. Для оружия можно указать два подтипа, в первом -
оружейное умение: рукопашный.бой, длинные.лезвия, короткие.лезвия, проникающие,
топоры, посохи, дубины.и.палицы, копья, луки, арбалеты, пращи, разнообразное, а
во втором - для какой руки предназначено оружие: правое, левое, двуручное,
дальнее (второй подтип в команде можно не указывать). Все приведенные выше
варианты в команде можно писать с сокращениями.

Примеры:
  биржа предложения одежда *допслот
  клан склад оружие *топоры *двуручное
  склад ингредиент *фиолетовый

   Поиск по персонажу. Данный параметр поиска определяет, какой персонаж
планирует пользоваться найденными предметами. Соответственно в список не попадут
предметы, которые персонажу могут быть недоступны из-за его уровня, профессии
или расы. Параметр указывается после знака = (например =минотавр). Самое
популярное значение этого параметра: =я, в этом случае фильтр отсеет все
предметы, недоступные текущему выбранному персонажу. Вместо этого можно явно
указать уровень персонажа: =<число> (например =15), а также его профессию и расу
(например =пещерный.тролль =воин). Названия рас и профессий можно сокращать до
нескольких букв, кроме того, у некоторых рас и профессий существует
двухбуквенное сокращение, которое можно использовать наряду с обычным. Например,
рыцарь смерти можно указать как =рыц или как =дк. Воин можно обозначить как =вн,
а =во - это обозначение для вора. Список особых сокращений: воин - вн, вор - во,
рыцарь смерти - дк, полуэльф - пэ, высокий эльф - вэ, лесной эльф - лэ, ночной
эльф - нэ, подгорный гном - пг, древесный гном - дг, пещерный тролль - пт,
болотный тролль - бт.

Примеры:
  биржа предложения книга =я
  клан склад оружие =лекарь =лесной.эльф =15
  склад подщит =друид =болотный.тролль =41

   Поиск по оценке. Данный параметр представляет собой число и указывается после
знака ! (например !30). В этом случае фильтр будет отсеивать все предметы,
оценка у которых ниже указанной величины. Если вместе с этим используется и
поиск по персонажу и в нем указана профессия (явно или с помощью параметра =я),
то будет использоваться оценка предмета для данной профессии, иначе будет
использоваться максимальная оценка.

Примеры:
  биржа предложения оружие !200
  клан склад одежда *палец =я !30
  склад оружие *копья =паладин !100

   Поиск по бонусу. Данный параметр позволяет вам найти все предметы с
определенным интересующим вас аффектом или модификатором. Параметр указывается
после знака ? (например ?заточить или ?ЗАЩИТА). Все предметы, не обладающие
указанным бонусом, будут отсеяны. Бонус ищется и в базовых характеристиках
предмета, и в уникальных свойствах, и во вставленной руне. Если написать
название заглавными буквами, то будет производиться поиск по аффекту, например
?сила - это бонус к характеристике Сила, а ?СИЛА - это аффект. Если нужно найти
бонус к умению, то вначале можно вставить слово 'умение' (например использовав
аргумент ?умение.сбить.противника), аналогично слово 'заклинание' для поиска
бонусов к заклинанию (например ?заклинание.яд). Будьте внимательны с
очередностью модификаторов по алфавиту, например параметр ?заклинание.сила будет
искать бонус к заклинанию 'массовая сила', а не 'сила', так как первое стоит по
списку раньше. Для поиска модификаторов к заклинанию 'сила' нужно использовать
параметр ?2заклинание.сила. После названия бонуса можно поставить знак + и
указать минимальную требуемую величину данного бонуса (например использовав
аргумент ?массовый.вред+10 или ?БЛАГОСЛОВЛЕНИЕ+3). В данном случае для
модификатора указывается его величина, а для аффекта - градация.

Примеры:
  биржа предложения подщит ?ПОЛЕТ
  клан склад одежда *голова ?УСКОРЕНИЕ+3
  склад оружие *длинные ?дамролл+5

   Поиск по времени. Данный тип поиска доступен только при просмотре биржевых
лотов и способен отсеять более старые лоты, показав только те, что были
выставлены недавно. Параметр представляет собой число и указывается он после
знака + (например +5). Данный фильтр будет отсеивать все лоты, выставленные
ранее, чем указанное число реальных часов назад.

Примеры:
  биржа предложения книга +24

   Поиск по имени. Параметры, которые начинаются с других символов, не
перечисленных выше (например просто слово 'латы'), считаются поиском по имени
предмета. Фильтр оставит только предметы, похожие по названию на указанный
параметр.

Примеры:
  биржа предложения одежда латы
  клан склад оружие трезубец
  склад реагент перо.фазана
