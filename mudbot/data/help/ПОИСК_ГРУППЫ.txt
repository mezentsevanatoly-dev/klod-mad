ПОИСК_ГРУППЫ ГРУППОИСК ГПОИСК ГРУППЫ_ПОИСК ГРУПППОИСК ГРУППА_ПОИСК

   Сервис поиска группы представляет собой список персонажей, находящихся на
данный момент в поисках лидера или новых бойцов в свою группу. Вывести этот
список можно с помощью команды "группа поиск" или ее сокращения "гпоиск". В
списке будут указаны имена персонажей, их профессии и уровни, а также
комментарии, которые те пожелали оставить. Если вы обнаружили в списке
персонажа, подходящего для формирования группы, с ним можно связаться командой
"сказать <имя>".

   Добавить своего персонажа в список поиска группы можно с помощью команды
"группа поиск +". Также с помощью этой команды можно указать, являетесь ли вы
лидером группы, и оставить при желании любой комментарий, который более точно
будет отражать ваше пребывание в списке.

Синтаксис:
  группа поиск + [лидер] [<комментарий>] - добавить своего персонажа в список
поиска группы

   Удалить своего персонажа из списка можно командой "группа поиск -". Кроме
того персонаж автоматически будет удален из этого списка через некоторое время
после выхода из игры, а также при вступлении в какую-либо группу не в качестве
лидера (лидеры могут продолжать оставаться в списке, подыскивая новых персонажей
для своей группы).

Синтаксис:
  группа поиск - - удалить своего персонажа из списка поиска группы

   Также вы можете воспользоваться настройками специального режима для поиска
группы - режим группоиск. Он позволяет установить независимо друг от друга три
различных режима пользования списком поиска группы.

   режим группоиск инфо - включить/выключить автоматическое информирование о
новых добавившихся в список персонажах,
   режим группоиск авто - включить/выключить автоматическое добавление своего
персонажа в список поиска группы при входе в игру,
   режим группоиск лидер - (если включен режим Авто) добавляться в список в
качестве лидера.

Команды:
  группа поиск
  гпоиск
  группа поиск +
  гпоиск + лидер
  группа поиск + Инкарнации
  группа поиск -
  реж группоиск инфо
  реж группоиск авто
  реж группоиск лидер
