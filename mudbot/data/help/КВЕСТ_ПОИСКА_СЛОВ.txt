КВЕСТ_ПОИСКА_СЛОВ КВЕСТЫ_СЛОВА КВЕСТЫ_БУКВЫ

   В период проведения в игре новогоднего события включается квест поиска слов.
Состоит он в следующем. В некоторых зонах с некоторых мобов (в основном, с
ластмобов, но не всегда) падают буквы из загаданных слов. С определенного моба
будет падать строго определенная буква определенного слова. В букве будет
указано, из какого по номеру слова взята эта буква, и на каком по номеру месте
стоит эта буква в данном слове. Для некоторых слов известно, в каких зонах
падают буквы для них, а для некоторых - нет, это могут быть и города, и дороги,
и любые прочие зоны. Из каких мобов будут падать буквы - тоже заранее
неизвестно. Известно только, что при убийстве такого моба будет выведено
сообщение, что из этого моба можно получить букву от загаданного слова. Шанс
выпадения буквы из моба не является стопроцентным. Буква может выпадать из моба
неограниченное число раз. При выпадении буквы игрокам будет выдана подсказка, в
какой зоне может быть найдена еще одна буква того же слова. При выпадении из
моба буква "засчитывается" только лидеру группы. Записки с буквами хранить
необязательно, найденные буквы запоминаются на уровне сервера.
   Загаданные слова бывают трех видов: индивидуальные, групповые и для фракции.
   Индивидуальные слова предполагают меньшую награду и менее сложных мобов по
сравнению с другими видами, награду за каждое такое слово может по одному разу
получить каждый уникальный аккаунт, если выполняется условие: персонаж должен
добыть все буквы слова в соло, то есть у него в группе и в локации в момент
смерти моба из персонажей должен находиться только он один. Шанс выпадения буквы
для индивидуального слова - 66%.
   Групповые слова и слова для фракции предполагают более высокую награду, а
буквы из таких слов снимаются в более сложных зонах. Получая награду за сдачу
такого слова, лидер группы может выбрать нескольких персонажей, которые также
получат награду вместе с ним, если эти персонажи присутствовали при засчитывании
всех букв из сдаваемого слова. У каждого группового слова указано, для какого
количества персонажей лидер группы может попросить награду. Персонаж может
получить награду за каждое слово либо как лидер, либо как член группы. Награду
за слова для фракции могут получить только персонажи из фракций Инквизиция,
Ловцы Снов и Затерянный Рай, каждая из этих фракций получает награду только один
раз. Шанс выпадения буквы из слова для фракции - 50%, шанс выпадения буквы
группового слова: в зоне в режиме !бот - 66%, в противном случае - 33%.
   Вывести информацию по собранным/увиденным буквам квестовых слов можно с
помощью команды 'квесты слова'.
   Персонаж, у которого засчитаны все буквы какого-либо слова, может получить
награду за это слово с помощью команды 'квесты слова награда'. Персонажам,
собравшим слово в группе с лидером, требуется, чтобы лидер назначил персонажа
для получения награды за данное слово. Выдача наград доступна до окончания
новогоднего события.
   Награда за собранные слова:
 1. 7 букв, для фракции, для 5 персонажей, каждому: один предмет из любого моба
или квеста, все 5 предметов разные.
 2. 7 букв, для фракции, для 5 персонажей, каждому: 5 особенностей на предмет
без особенностей, 1 значок на аукцион, восстановление таймера 1 предмета.
 3. 6 букв, групповое, для 3 персонажей, каждому: 15000 славы, 5 баллов на
новогоднюю награду.
 4. 7 букв, групповое, для 5 персонажей, каждому: 1 инкарнация, 2 балла на
новогоднюю награду, 1 предмет из наград квеста охотника на чудовищ.
 5. 10 букв, групповое, для 5 персонажей, каждому: 2 предмета для выполнения
персональных квестов, 10.000.000.000 опыта (не более 20 максов), изучение умения
или заклинания чару (доступных профессии или из рукописи).
 6. 10 букв, индивидуальное, для 1 персонажа: 2 балла на новогоднюю награду, 1
инкарнация, 7.500.000 монет.
 7. 7 букв, индивидуальное, для 1 персонажа: 5 рун по выбору, 20 еловых веточек
(бирюза 100%).
 8. 10 букв, индивидуальное, для 1 персонажа: 1 значок на аукцион, герольд 3
недели, +1 особенность на 5 предметов без особенностей.
