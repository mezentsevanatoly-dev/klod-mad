ЗОНЫ ZONES ЗОНА

   С помощью команды 'зоны' вы можете узнать список всех подключенных к серверу
зон, примерное место их нахождения и уровни персонажей, на которых расчитана
зона. Помните, что уровни указаны для групп персонажей, а не для соло-зонинга.
Список зон можно просмотреть, включив с помощью аргументов команды один из
вариантов сортировки. Без аргументов список отсортирован по идентификатору зон.
Аргумент 'название' включает сортировку зон по названию, а 'уровни' - по уровню.
Также после команды 'зоны' можно указать определенный уровень, и тогда в список
попадут лишь те зоны, которые подходят по сложности к указанному уровню
персонажа.
   Также эту команду можно использовать с аргументом 'зоны области'. В этом
случае будет отображен список всех зон, для которых доступно создание зон
повышенной сложности, а также прогресс вашего персонажа в их открытии.

Синтаксис:
  зоны
  зоны название
  зоны уровни
  зоны 25
  зоны области
