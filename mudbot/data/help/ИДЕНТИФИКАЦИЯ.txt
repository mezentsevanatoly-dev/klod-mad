ИДЕНТИФИКАЦИЯ ФЛАГИ_ПРЕДМЕТА ФЛАГИ_ОРУЖИЯ ОРУЖЕЙНЫЕ_ФЛАГИ МОДИФИКАТОРЫ ЛОР
ПОЗНАТЬ ОПОЗНАТЬ ОПОЗНАНИЕ УНИКАЛЬНЫЕ_СВОЙСТВА УНИКАЛЬНЫЙ_ПРЕДМЕТ ФЛАГИ_ЗАПРЕТА

   У каждого предмета есть набор характеристик и свойств, которые вы можете
узнать с помощью заклинания 'познание' или используя специальные возможности
магазинов, биржи или складов. Этот процесс называется идентификацией предмета.
Идентификация предмета содержит следующую информацию:

1. Тип предмета, один из:

   Обычный    - простые предметы и контейнеры
   Одежда     - вещи, которые персонаж может на себя одеть
   Оружие     - оружие, которым можно сражаться
   Свиток     - магические свитки с заклинаниями, которые можно зачитывать
   Напиток    - магические напитки, которые можно пить
   Книга      - книги, из которых персонажи узнают новые заклинания и
                умения
   Ингредиент - специальные предметы, которые нужны для некоторых
                заклинаний
   Пища       - еда для утоления голода
   Ключ       - ключи для отпирания дверей и контейнеров
   Источник   - источники воды для утоления жажды
   Дверь      - двери
   Письмо     - письма, которые персонажи посылают друг другу по почте
   Доска      - публичные доски для общения
   Портал     - порталы между мирами
   Монеты     - кучки монет
   Реагент    - предметы для соединения с магическими символами
   Символ     - предметы для сборки магических рун
   Руна       - предметы для изменения характеристик других вещей

2. Необходимые для его использования характеристики персонажа: уровень, сила,
   ловкость, интеллект, мудрость и телосложение. Если предмет имеет требования
   выше, чем характеристики игрока, то использовать его не получится.
3. Флаги предмета, бывают следующие:

   ВЗЯТЬ      - предмет можно поднять с пола или достать из контейнера
   СВЕТ       - предмет светится
   ДЕРЖАТЬ    - предмет можно держать в левой руке
   РАССЫПЕТСЯ - предмет рассыпется, если его уронить на пол 
   ПК-СТАТЫ   - предмет влияет только на пк-характеристики персонажа
   !РЕНТ      - предмет нельзя унести на постой
   !ПРОДАТЬ   - предмет нельзя продать 
   !НАЙТИ     - предмет нельзя найти заклинанием 'найти предмет'
   !ВЫБИТЬ    - предмет нельзя выбить из рук
   !УКРАСТЬ   - предмет нельзя украсть
   !ПК        - предмет не получает флага принадлежности

4. У некоторых предметов бывают так называемые флаги запрета, которые означают,
   что данный предмет не могут использовать определенные расы или профессии.
5. Вес, таймер, материал.
6. Аффекты, которые предмет накладывает на персонажа, если предмет одеть или
   взять в руки.
7. Модификаторы, которые изменяют характеристики персонажа, если предмет одеть
   или взять в руки.
   На действие модификаторов, увеличивающих раскачку навыков (умений, заклинаний
   и оружейных умений) персонажа, накладываются ограничения в зависимости от
   того, каков источник этих модификаторов.
   Если модификаторы действуют из уникальных свойств предмета (например
   зачарованного заклинаниями 'заколдовать доспехи' или 'заколдовать оружие'),
   то для каждого навыка выбирается два самых больших модификатора, добавляющего
   к нему бонус. К каждому навыку персонаж получит бонус только от этих двух
   самых больших модификаторов из уникальных свойств (или меньшего количества,
   если в уникальных свойствах предметов меньше двух модификаторов к данному
   навыку). Остальные модификаторы к раскачке данного навыка из уникальных
   свойств предметов действовать не будут.
   Модификаторы к раскачкам навыков, получаемые из особенных свойств предмета
   (свойств, появляющихся на предметах из инстов повышенной сложности),
   добавляются так же, как и из уникальных: для каждого навыка выбирается два
   максимальных бонуса, которые без каких-либо штрафов добавляются к раскачке
   навыка персонажа.
   Модификаторы к раскачкам навыков, получаемые из базовых характеристик
   предмета (характеристик, присутствующих на предмете вне зависимости от его
   уникальных свойств) также ограничиваются по величине. После расчета суммы
   модификаторов из базовых характеристик предмета к определенному навыку
   персонажа конечный результат будет зависеть от уровня персонажа. Полученная
   сумма модификаторов разбивается на три слагаемых А, В и С. Слагаемое А
   равняется всей сумме модификаторов, но по величине не более, чем уровень
   персонажа. Слагаемое В равняется величине сумма-А, и также не может превышать
   по величине уровень персонажа. Слагаемое С равняется величине сумма-А-В.
   Конечный результат, который получит персонаж в качестве бонуса к раскачке
   данного навыка, будет равняться А + В/2 + С/4.
   На модификаторы к навыкам, действующим из вставленных в предметы рун, никаких
   ограничений не накладывается.
8. У оружия также могут быть следующие флаги, определяющие его использование:

   В_ПРАВУЮ_РУКУ - оружие можно взять в правую руку (вооружиться)
   В_ЛЕВУЮ_РУКУ  - оружие можно взять в левую руку (держать)
   В_ДВЕ_РУКИ    - оружие можно взять в две руки
   ДАЛЬНЕГО_БОЯ  - оружие для дальнего боя (лук,арбалет или праща)
