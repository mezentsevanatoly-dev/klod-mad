ТУРНИРНОЕ_РАСПИСАНИЕ

   Турнирное расписание применяется в переходящих турнирных зонах для
определения новой даты проведения турнира. Используют турнирное расписание две
противоположных стороны. Фракция владелец турнирной зоны может установить
расписание обороны данной зоны, перечислив дни недели и часы, когда бойцы данной
фракции готовы защищать право владения данной зоной. Другие же фракции, исходя
из установленного фракцией-владельцем расписания, могут назначать конкретное
время проведения очередного турнира, чтобы оспорить это право у владельца.

   Просмотр раписания турнирной зоны осуществляется с помощью команды:
      турнир зона <название> расписание
   На экран будет выведено текущее действующее расписание обороны турнирной
зоны, а также время следующей атаки на данную зону, если оно установлено.

   Установка расписания обороны турнирной зоны доступна фракции-владельцу сразу
после победы в очередном турнире. Пока фракция-владелец не установила
собственное расписание, для зоны действует стандартное расписание обороны. На
устанавливаемое фракцией-владельцем расписание действует несколько ограничений.
Расписание обороны должно занимать не менее одного часа в каждый день недели и
не менее 10 часов в неделю суммарно. Также все часы из расписания обороны должны
попадать в промежуток с 9 часов утра до 23 часов вечера. Установленное
расписание обороны в дальнейшем можно будет поменять, с двумя исключениями. Если
в некоторый день было установлено новое расписание обороны, то изменить его на
другое будет нельзя в течение этого и следующего дня. Точно также, если в
некоторый день на турнирную зону была назначена атака, то в этот день и в
следующий расписание обороны менять будет нельзя.

   Смена текущего расписания обороны фракцией-владельцем производится с помощью
промежуточного расписания - отдельного экземпляра расписания, с которым можно
делать что угодно. Вывести текущее значение промежуточного расписания можно с
помощью команды
      турнир зона <название> расписание результат

   Добавить или удалить период времени в промежуточное расписание можно с
помощью команд
      турнир зона <название> расписание + [пн|вт|ср|чт|пт|сб|вс|номер|все]
час1-час2
      турнир зона <название> расписание - [пн|вт|ср|чт|пт|сб|вс|номер|все]
час1-час2
   Можно указать название дня недели, для которого производится установка, или
номер дня в неделе (1 - понедельник, 7 - воскресенье). Если день недели не
указан или использован параметр "все", то установка будет производиться для всех
дней недели одновременно.
   Примеры:
      турнир зона 1 расписание + вт 11-13 - добавить период 11-13 часов к
расписанию обороны во вторник
      турнир зона 1 расписание - все 16-23 - удалить период 16-23 часов из
расписания обороны во всех днях недели
      турнир зона 1 расписание + 4 20-21 - добавить период 20-21 часов к
расписанию обороны в четверг

   Применить промежуточное расписание в качестве текущего действующего
расписания обороны можно с помощью команды
      турнир зона <название> расписание применить
   Будьте осторожны, после применения этой команды поменять раписание на
какое-либо другое можно будет только по истечению следующего дня.

   Фракции, которые не являются владельцами данной турнирной зоны, могут
назначать атаки на нее с целью завладеть этой зоной. У каждой переходящей
турнирной зоны есть минимальный период владения, например 1 неделя, который
начинается сразу же после того, как завершился очередной турнир. Нельзя
назначить очередную атаку на переходящую зону до истечения этого периода. Если
же этот период истек, то назначать новую атаку можно на любой момент времени с
двумя условиями. Этот момент времени должен удовлетворять установленному
фракцией-владельцем расписанию обороны. Также момент следующей атаки не может
происходить в один день с его назначением, т.е. атаку нельзя назначать на
сегодняшний день. Установленный момент атаки можно будет поменять в будущем,
однако этого нельзя будет сделать сразу в тот же день и в день следующий после
назначения.

   Назначить момент атаки можно с помощью команды
      турнир зона <название> расписание атака ДД.ММ.ГГГГ ЧЧ:ММ
   Пример:
      турнир зона 1 расписание атака 16.04.2017 13:30

   Если фракция-владелец меняет расписание обороны, то назначенная атака будет
отменена, если она не удовлетворяет новому установленному расписанию.

   У каждой переходящей турнирной зоны есть максимальный период владения,
например, 2 недели. Если за это время после проведения предыдущего турнира не
было назначено ни одной атаки, то атака на турнирную зону назначается
автоматически. Такое назначение атаки будет произведено согласно стандартному
расписанию обороны турнирных зон, а не тому расписанию обороны, что было
установлено фракцией-владельцем. Автоматически назначенную атаку нельзя отменить
изменением расписания обороны зоны. Если ни одна фракция не принимает участие в
турнире (назначенном автоматически или какой-либо фракцией), то после завершения
турнира зона теряет своего владельца и становится бесхозной.
