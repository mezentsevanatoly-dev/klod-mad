СИМВОЛЫ БОЛЬШОЙ_СИМВОЛ СРЕДНИЙ_СИМВОЛ МАЛЫЙ_СИМВОЛ

   Символы необходимы для сборки магических рун, каждому символу соответствует
определенная руна. Чтобы создать из символа руну, персонажу необходимо собрать
для этого некоторое количество реагентов. Список этих реагентов можно прочитать,
осмотрев символ или применив к нему заклинание Познание. Также с помощью
Познания можно узнать минимальный уровень, необходимый для использования руны,
созданной из этого символа. Символы бывают трех размеров: малые, средние и
большие. Эти размеры соответствуют размерам создаваемых из них рун. Символы
могут быть сняты с некоторых мобов во многих зонах по всему миру. У некоторых
мобов можно заполучить случайный малый символ, у некоторых - случайный средний,
у некоторых, наиболее опасных мобов, - случайный большой. После использования
символа для сборки руны он исчезает.
