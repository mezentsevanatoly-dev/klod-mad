# ФИЛЬТРЫ — как искать предметы на КСК и бирже

Синтаксис — из справки ФИЛЬТР_ПРЕДМЕТОВ, КЛАНСКЛАД, БИРЖА, СКЛАД (`СПРАВКА.md`). Фильтры конкретного персонажа — в `Экип\<имя>.md`.

## Где работает
- `кск [*] [%] [!] [:<отдел>] <строка>` — клановый склад (`ксклад`, `клан склад`). `*` — показать отдел вещи, `%` — таймер, `!` — оценку.
- `склад [*] [%] [!] [:<отдел>] <строка>` — личный склад.
- `биржа предложения <строка>` (`б п`, `бир п`, `биржа предл`) — лоты биржи. Строка лота: `номер. [цена] (таймер) !оценка! название`.

## Строка фильтра
1. **Тип — первым словом** (можно сокращать): все, одежда (`од`), оружие (`ор`), подщит (держать в левой руке), книга, свиток, напиток, ингредиент, реагент, символ, руна, инструмент, пища, ключ, источник, прочее, уникальный, особенный, рунный; только биржа: мой, клан.
2. Дальше в любом порядке:

| Знак | Что | Пример |
|---|---|---|
| `*` | подтип. Одежда — слот: допслот, голова, шея, тело, плечи, талия, кисти, руки, ноги, обувь, запястье, палец, щит. Оружие — умение (рукопашный.бой, длинные.лезвия, короткие.лезвия, проникающие, топоры, посохи, дубины.и.палицы, копья, луки, арбалеты, пращи, разнообразное) и вторым `*` рука (правое, левое, двуручное, дальнее) | `од *шея`, `ор *топоры *двуручное` |
| `=` | для кого: `=я` (текущий персонаж), уровень `=25`, профессия, раса. Сокращения: вн воин, во вор, дк рыцарь смерти, пэ полуэльф, вэ высокий эльф, лэ лесной эльф, нэ ночной эльф, пг подгорный гном, дг древесный гном, пт пещерный тролль, бт болотный тролль | `=дк =26`, `=варвар =20` |
| `!` | оценка не ниже N (для профессии из `=`, иначе максимальная) | `!50` |
| `?` | бонус. строчными — модификатор (`?ловк`, `?ас+10`), ЗАГЛАВНЫМИ — аффект (`?ПОЛЕТ`, `?УСКОРЕНИЕ+3`). Умение — `?умение.<имя>`, заклинание — `?заклинание.<имя>` (`?2заклинание.сила` — второе по алфавиту). `+N` — не меньше N (модификатор — величина, аффект — градация) | `?доп.атак`, `?дамролл+5` |
| `+` | только биржа: лоты не старше N реальных часов | `+24` |
| слово | по имени предмета | `латы`, `сталь.панц` |

## Проверено в игре (15.11, Айлина, КСК)
- **Работает только один `?`, последний.** `?ПОЛЕТ ?доп.атак` даёт то же, что `?доп.атак` (9 вещей), а `?доп.атак ?ПОЛЕТ` — то же, что `?ПОЛЕТ` (12 вещей). Первый `?` молча отбрасывается.
- Нужны два бонуса — делаем два запроса и берём вещи, которые есть в обоих списках. Пример: `кск * од =дк =26 ?ПОЛЕТ` и `кск * од =дк =26 ?доп.атак` -> в обоих только колючее хитиновое ожерелье *** (`кск х`: ПОЛЕТ [2], умение «Дополнительная атака» +5, АС +3, оценка Дк 48).
- `?доп.атак` находит модификатор «Умение 'Дополнительная атака'».
- `+N` писать слитно: `?ас+4` — 3 вещи на шею, `?ас +4` (с пробелом) — «Ничего». В старых строках «Сборной солянки» (`?ас +4`, `?ас +2`) пробел мешает.

## Осмотр найденного
- `кск инф <вещь>` / `биржа инф <лот>` — бесплатно, без уникальных свойств и руны.
- `кск х <вещь>` / `биржа х <лот>` — полная идентификация; уникальная или с руной — 100 монет. Вещь уникальная — смотреть только `х` (слова пользователя 03.11, 06.11). Второй экземпляр: `кск х 2<вещь>`.
- `экипировка <бонус>` — сколько бонуса на надетом (`экипировка ловк`, `экипировка ПОЛЕТ`).

## Оценка
Число полезности одежды для профессии (Ва, Дк, Ма …); только у одежды. Видна на бирже, складе, при опознании. На стоимость прямо не влияет.
