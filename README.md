# Сфера Миров — рабочий проект

Клиент «Погоняем лысого» (1.2), бот группы, правила, задания, локальный тестовый стенд и данные по игре.
Приватный репозиторий: здесь личные заметки, профили не входят (см. «Чего здесь нет»).

**Снимок:** 18.11.2026, 16:15.

## С чего начать

| Файл | Зачем |
|---|---|
| `КАРТА_ФАЙЛОВ.md` | что за файл/папка, зачем, когда открывать, что устарело |
| `CLAUDE.md` | что читать в начале каждой сессии |
| `ОГЛАВЛЕНИЕ.md` | рабочий указатель: где что лежит, инструменты |
| `ПРАВИЛА\` | правила работы (общие, эксплор, клиент, уровни теста, задания) |
| `ЗАДАНИЯ\` | что открыто и что осталось по уровням (стенд / тест основы / основа) |
| `НАПОМНИТЬ.md` | что не доделано |

## Что где

- `МАД ГРАФИКА\` — основа: клиент (`server.py`, `index.html`, `jmcprofile.py`), данные (`data\game.db`, зоны, карточки мобов), релизы.
- `МАД БОТ\` — бот группы: `bot.py`, `play.py`, базы.
- `МАД тест\` — локальный стенд: сервер Sow.exe 4.73, MSDP-прокси, копия клиента, копия бота, скрипты запуска.
- `mudbot\` — Python-инструменты и данные (клетки, мобы, справка, вики, карты).
- `ЗОНЫ\`, `ПЕРСОНАЖИ\`, `Экип\`, `РАСХОДНИКИ\`, `СКРИПТЫ\`, `НАЙДЕНО\` — знания по игре.
- `JMC БОТ АЙЛИНА\areas`, `JMC БОТ ИНКА\areas` — маршруты `.botp` и `_mob.csv`.
- `MUDMapper2023\Maps\` — карты зон (.mm2) для координат.

## Запуск

Клиент (Windows, Python 3.10+ и Edge/Chrome):

```
python -X utf8 server.py            # затем http://localhost:8765
```

или двойной щелчок `МАД ГРАФИКА\Погоняем лысого.vbs`.

Локальный стенд: `МАД тест\сервер\run_server.py` (Sow.exe), затем `МАД тест\прокси\msdp_прокси.py`,
клиенты — с `--game-port 5556`; ярлыки `МАД тест\клиент\Айлина (тест).vbs` и `Кимпи (тест).vbs` делают это сами.

## Чего здесь нет (намеренно)

- `аккаунт_*.txt`, `пароль_тест.txt` — пароли и имена аккаунтов.
- `профиль_*.txt` — личные алиасы/триггеры/хоткеи персонажей.
- Логи `*.log` (самый большой — 124 МБ), `presence_*`, `экип_*`, `реск_*`.
- Архивы (`*.zip`, `*.rar`), бинарники сервера (`Sow.exe`, `Kernel.dll`), `dist\*.zip`.
- Старые копии и свалки: `Мад\`, `_архив_мад\`, `JMC\`, `MMC\`, `_временное\` и т. п.

Полная папка со всем этим остаётся на рабочем компьютере.
